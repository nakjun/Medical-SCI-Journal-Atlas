# 전체 저널 게재율 조사 · 2026-11-05

175개 저널 전체에 조사 기록을 남긴 1차 조사다. 접근 제한으로 미확인인 저널의 검증은 완료되지 않았다. 수치를 확인하지 못했다는 사실은 미공개임을 뜻하지 않는다. 현재 모달 표시 대상은 52개(기존 Wiley 32개 + 신규 20개)다.

공식 출판사·학회 안내만 채택했다. 검색 색인은 실시간 원문과 다를 수 있어 확인 방법을 표시한다. 연구 논문 속 실험 수치, 학회 채택률, 다른 저널 수치, 출판사 전체 평균은 제외했다. 오래된 회고나 전망치는 현재 게재율로 대체하지 않았다. JBHI는 2025년 안내임을 모달에 명시한다. 확인일과 집계 기간은 별개이며, 출판사별 분모·기간 차이 때문에 단순 비교에 주의해야 한다.

Elsevier는 브라우저에서 7개 Insights 페이지를 읽어 3개 수치를 확인한 뒤 콘텐츠 접근 오류가 발생했다. 나머지는 검색 도구 접근도 제한돼 재확인이 필요하다. IOP는 Biofabrication 메인 열람 후 상세 지표에서 CAPTCHA가 나타나 진행하지 않았다. IEEE의 일부 Xplore·Computer Society 페이지도 접근 오류였다.
